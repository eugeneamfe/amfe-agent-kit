# Приёмка Threads Workflow v1

Дата: 2026-10-01. Основание: [спецификация 0.2](../../specs/threads-workflow.md). Проверяется переносимый пакет, а не фактический рост аккаунта.

## Метод и ограничения

Поведенческие проверки — ручные scenario walkthroughs независимых от автора пакета агентов на синтетических материалах. Ответы записаны после чтения skill; контексты логически разделены, но отдельные свежие сессии и автоматическое обнаружение skill в интерфейсе не тестировались. Предварительная самооценка генераторов ответов отделяется от оценки другого ревьюера. Локальные профиль/копирование/длины проверяются файловыми действиями в изолированных проектах. Для браузера используются заданные UI-состояния и трассы решений: это симуляции, не live-интеграция. Реальные аккаунты и внешняя отправка не использовались. Прохождение одного прогона не доказывает устойчивость поведения на всех будущих запросах или эффективность алгоритмического роста.

[Контроль без skill](baseline.md) сохранён отдельно. Он не показал обязательной ошибки без skill; превосходство над контролем не заявляется.

## Проверка пакета

Из корня репозитория:

```sh
uv run --with PyYAML python docs/validation/threads-workflow-v1/check_package.py
```

PyYAML — временная зависимость разработки для этой проверки, не зависимость пользователя skill. Проверяется копирование всего каталога в новый `.agents/skills/threads-workflow`, замыкание относительных ссылок внутри копии, YAML UI, отсутствие обязательных tool dependencies, точная лицензия и известные маркеры частных путей. [Проверяющий скрипт](check_package.py) не оценивает качество ответов.

Штатный `quick_validate.py` из Codex skill-creator запускается на `skills/threads-workflow`; в используемой среде выполнен через `uv run --with PyYAML`. Результат: `Skill is valid!`.

Переносимость: `PASS: relocated bundle; 8 relative links; YAML; license; privacy markers`. Публичный состав также проверяется вручную: ссылки автора/репозитория — обязательная отметка происхождения; пользовательских аккаунтов, медиа, статистики и редакционных предпочтений в пакете нет.

## Итог

[Независимый вердикт](independent-review.md): текущий пакет и финальные ответы не имеют блокирующих/существенных замечаний. Все T01–T16 выполнены в описанном объёме: T14/B принят после второго повтора, T15/B — после первого; остальные — по исходным результатам. Все применимые критерии независимой рубрики выполнены. Это приёмка решений по синтетическим входам с файловыми проверками, не подтверждение live-интеграции или эмпирической эффективности роста.

Штатная валидация и копирование повторены после последней правки content.md — PASS. Отдельно проверены ссылки документации и публичный состав. Первичные неуспешные ответы оставлены как свидетельства цикла исправлений, а не образцы готового контента.
