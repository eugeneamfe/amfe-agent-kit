# T13: поведенческий прогон

## Точный запрос

А: познакомиться с автором, факт первый хлеб/жёсткая корка, только текст.

Б: обсуждение конкретной задачи — тесто липнет к рукам, нужен опыт читателей.

## Исходные данные и изоляция

Два независимых контекста, без профиля. В Б не перенесена первая выпечка из А.

## Полный полученный ответ / артефакт

### Полный ответ А (только текст)

Впервые испёк хлеб. Корочка вышла жёсткой.

Вот такое начало знакомства с домашней выпечкой: хлеб уже есть, а корочку ещё предстоит понять.

### Полный ответ Б

Тесто липнет к рукам. Хочу разобраться с этой задачей через опыт тех, кто печёт: по каким признакам вы решаете, что делать дальше — продолжать замес, дать тесту постоять или менять количество муки?

Редакторская заметка: цель — обсуждение конкретной трудности с людьми, которые пекут. Подача — описание задачи и один вопрос; варианты в вопросе не заявлены как рекомендации. CTA — поделиться признаками и опытом решения. Ожидаемый эффект — получить применимые наблюдения; показатель — ответы, где есть условия и результат. Длина измерена Python, Unicode code points.
