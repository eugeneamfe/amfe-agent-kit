# Threads Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Реализовать переносимый threads-workflow v1 по согласованной редакции 0.2.

**Architecture:** Короткая точка входа выбирает базовую работу или дополнительный браузер. Четыре references описывают профиль, контент, браузер и анализ; нейтральный шаблон профиля копируется только по поручению.

**Tech Stack:** Markdown, YAML метаданные Codex; нет runtime-зависимостей.

**Spec:** [threads-workflow v1](../../specs/threads-workflow.md)

## Global Constraints

- Базовая работа без браузера, авторизации, установки зависимостей и обязательной анкеты.
- API/MCP, установщик, расписание и массовые действия вне v1.
- Профиль и материалы пользователей находятся вне каталога skill.
- Текущее поручение приоритетнее локальных предпочтений, затем общие рекомендации.
- Сохранять авторство, источник и MIT; только синтетические примеры.
- Публикация требует конкретного поручения, результат проверяется на площадке.

## Review Focus

- Частичный профиль с ручными полями: точечная запись без потери данных (T03–T05).
- Юмор и неподтверждённый опыт: очевидная шутка допустима, факты не выдуманы (T14).
- Частичный доступ к обсуждениям и устаревшие данные: границы и возраст явно отмечены (T07–T09).
- Неопределённая отправка: проверить присутствие перед повтором (T11).
- Несколько изменённых факторов: нет ложной атрибуции, следующий эксперимент ограничен (T16).
