# Инструкции репозитория Amfe Agent Kit

Перед работой прочитай и соблюдай `skills/git-workflow/SKILL.md`.

Репозиторий содержит коллекцию переносимых skills и инструкции их подключения. Не добавляй личные данные, адреса частных проектов и секреты. Проверяй целостность skill, локальные ссылки и соответствие инструкций подключения фактической структуре.

При добавлении skill используй `skills/<name>/SKILL.md`. Сохраняй указание автора, ссылку на исходный репозиторий и копию LICENSE внутри каждого распространяемого каталога skill. Не добавляй незавершённые skills в каталог README.
