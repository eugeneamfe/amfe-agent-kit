# Инструкции репозитория Amfe Agent Kit

Перед работой прочитай и соблюдай `skills/git-workflow/SKILL.md`.

Репозиторий содержит коллекцию переносимых skills и инструкции их подключения. Не добавляй личные данные, адреса частных проектов и секреты. Проверяй целостность skill, локальные ссылки и соответствие инструкций подключения фактической структуре.

При добавлении skill используй `skills/<name>/SKILL.md`. Сохраняй указание автора, ссылку на исходный репозиторий и копию LICENSE внутри каждого распространяемого каталога skill. Не добавляй незавершённые skills в каталог README.

## Актуальность README

При изменении проекта проверяй корневой README и README затронутых skills, инструментов и других компонентов. Если изменения затрагивают описанные возможности, поведение, структуру, установку, настройки, зависимости или примеры использования, обновляй соответствующие README в той же задаче и включай их в коммит с изменениями. Не откладывай актуализацию до отдельной задачи или выпуска. Перед завершением проверь соответствие документации фактическому состоянию; если обновление не требуется, кратко объясни это в итоговом отчёте. Подробные общие правила закреплены в `skills/git-workflow/SKILL.md` и применяются также в проектах, подключивших этот skill.
