# Amfe Agent Kit

Авторская коллекция переиспользуемых skills от [Eugene Strebkov / eugeneamfe](https://github.com/eugeneamfe).

Источник: [eugeneamfe/amfe-agent-kit](https://github.com/eugeneamfe/amfe-agent-kit).

## Skills

- [git-workflow](skills/git-workflow/SKILL.md) — отдельные ветки и рабочие деревья, независимое ревью, своевременное обновление README, локальные коммиты, разрешения на push и merge, безопасная очистка.

## Подключение к проекту

1. Возьми `skills/git-workflow/` из выбранного коммита этого репозитория.
2. Скопируй каталог целиком в `.agents/skills/git-workflow/` целевого проекта. Существующий каталог сначала сравни с новой версией; не перезаписывай локальные изменения.
3. Добавь в корневой `AGENTS.md`: «Перед работой прочитай и соблюдай [.agents/skills/git-workflow/SKILL.md](.agents/skills/git-workflow/SKILL.md)». Сохрани остальные инструкции проекта.
4. В документации проекта запиши ссылку на этот репозиторий и идентификатор исходного коммита. Сохрани авторство и файл LICENSE внутри каталога skill. Проверь ссылки и включи копию skill и изменение `AGENTS.md` в ревью и коммит задачи.

Копия skill работает без доступа к исходному репозиторию. Обновления применяются явно: сравнение версий, сохранение локальных дополнений, проверка, независимое ревью и локальный коммит. Submodule и симлинки не нужны. Для явного вызова установленного skill используй `$git-workflow`.

Подключённый `git-workflow` требует проверять README проекта и затронутых компонентов и обновлять их в той же задаче и коммите, если изменения влияют на их содержание. Это правило применяется и при разработке самого Amfe Agent Kit.

Skill не даёт разрешения на push, merge или публикацию. Эти действия требуют отдельного поручения пользователя.
