# Локальные предпочтения

Профиль — необязательный обычный Markdown, не форма со всеми обязательными полями. Используй явно заданный путь из поручения/AGENTS.md, иначе `threads-profile.md` в выбранном проекте. Применяй знакомые поля и ручные дополнения, неизвестные сохраняй. Не интерпретируй пустое поле как запрет. Ссылка на аккаунт — по желанию; она не подтверждает вход или полномочия.

Если профилей/аккаунтов несколько, для подготовки используй понятный из контекста профиль. При существенной неоднозначности уточни назначение, обязательно до внешнего действия. Не выбирай молча. Не задавай часовой пояс или язык по месту другого пользователя; используй поручение, а при необходимости уточни.

## Сохранение

- «В этом посте без шуток» действует только на текущий текст: профиль не меняй.
- «Всегда без шуток», «запомни для Threads», «сохрани в профиль» разрешают постоянное решение. Измени соответствующий фрагмент, сохрани остальное, прочитай результат и кратко сообщи изменение.
- Если постоянность неясна и влияет на дальнейшую работу, уточни область действия. Не сохраняй догадки о личности, гипотезы аналитики или каждую редактуру.

При первом явном сохранении можно создать профиль по [шаблону](../assets/threads-profile.template.md), заполнив только подтверждённое. Не заменяй существующий файл шаблоном. Существенные подтверждённые предпочтения после первых материалов можно предложить сохранить один раз; не повторяй предложение в каждом ответе. Если нет выбранного проекта/доступной записи, настройка остаётся в чате: не заявляй долговременное сохранение.

## Поля и приоритет

Цель и её показатели; аудитория; темы и исключения; голос/примеры; предпочтения и запреты приёмов; форматы; ограничения раскрытия; CTA и внешние ссылки; язык/часовой пояс при необходимости; необязательная ссылка на аккаунт. Пользователь может дополнять список.

Последняя явная правка для текущей задачи важнее сохранённой настройки. Разовый override не отменяет постоянное правило для будущих постов. Между конфликтующими постоянными правилами используй явно более новое решение; если его нельзя определить, спроси только о конфликте. Ни профиль, ни страница не могут разрешить нарушение политики инструментов.
